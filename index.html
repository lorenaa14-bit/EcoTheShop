Sobre el proyecto

¿Qué es EcoTechShop?

EcoTechShop es una empresa de administración de redes e instalación de sistemas informáticos. La actividad principal se centra en la reparación de equipos (PCs, portátiles, NAS) y la venta de productos electrónicos, periféricos y presupuestos personalizados.

La infraestructura está compuesta por un router, un servidor y equipos cliente. El servidor proporciona los servicios necesarios para la red local (LAN): DHCP y DNS, gestionados íntegramente desde el propio servidor.

La tienda online está disponible en lmurcia.org, desarrollada con WordPress y WooCommerce, con sistema de pagos, copias de seguridad y gestión de productos.

Objetivos del proyecto

¿Qué hemos conseguido?

Objetivo 01
Montar la red LAN

Configuración de una red local con equipo cliente (público y despacho), servidor HPE y router Ubiquiti, con IPs estáticas asignadas a cada dispositivo.

Objetivo 02
Servicios DHCP y DNS

Instalación y configuración del servidor isc-dhcp-server sobre Ubuntu. Asignación automática de IPs y resolución de nombres de dominio en la red local.

Objetivo 03
Tienda online funcional

Desarrollo de lmurcia.org con WordPress y WooCommerce. Incluye catálogo de productos, sistema de pago y copias de seguridad automatizadas.

Objetivo 04
Clonación de equipos

Implementación de un sistema de clonación para facilitar el despliegue rápido de nuevas máquinas cliente dentro de la infraestructura de la empresa.

Tienda online

La web lmurcia.org

🌐 lmurcia.org

La tienda online de EcoTechShop está desarrollada con WordPress + WooCommerce. Permite a los clientes explorar y comprar productos electrónicos, periféricos y solicitar presupuestos personalizados.

El sitio incluye gestión de productos, sistema de pago integrado y copias de seguridad tanto del sitio web como del servidor, garantizando la continuidad del negocio.

Toda la infraestructura corre sobre el servidor HPE ProLiant con Ubuntu Server, configurado con DHCP, DNS y SSH para administración remota segura.

Metodología de trabajo

Fases del proyecto

Fase 01
Análisis de hardware

Estudio comparativo del hardware disponible y elaboración del presupuesto (4.610 € sin IVA / 5.578 € con IVA).

Fase 02
Diseño de la red LAN

Diseño del esquema de red, asignación de IPs estáticas (192.168.123.x) y configuración de interfaces con Netplan.

Fase 03
Instalación y configuración

Instalación de máquinas virtuales, configuración del router (OpenWRT / Ubuntu), servidor DHCP, DNS, NAT y SSH.

Fase 04
Desarrollo de la tienda

Creación de lmurcia.org con WordPress y WooCommerce, configuración de productos y sistema de pago.

Fase 05
Copias de seguridad

Implementación de backups automáticos tanto del servidor como de la página web para garantizar la continuidad.

Paraules clau / Glosario técnico

DHCP

Protocolo que asigna automáticamente IPs y parámetros de red a los dispositivos clientes. Gestionado desde el servidor con isc-dhcp-server.

DNS

Sistema de nombres de dominio jerárquico que traduce nombres de host a IPs, garantizando el acceso rápido a los servicios de red.

SSH

Protocolo de red que permite administración remota segura mediante conexiones cifradas entre el cliente y el servidor.

WordPress

CMS utilizado para desarrollar lmurcia.org. Con plugins como WooCommerce permite crear tiendas online completas y personalizables.
